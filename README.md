### 🎯 Selected Industry Work

* **[Causal ML remarketing](https://sergiomorapardo.github.io/work/causal-ml-remarketing/)** — Built and led an ML decision engine across eight countries, reaching ~12M monthly users. ML optimizations generated ~US$1M in monthly incremental GMV versus persistent holdouts.
* **[Personalized discovery & ranking](https://sergiomorapardo.github.io/work/personalized-product-discovery/)** — Led ML design and experiment evaluation for a personalized affiliate feed. An A/B test across ~5.2M sessions in four countries showed 20–26% engagement lift across the funnel.
* **[Applied LLM evaluation](https://sergiomorapardo.github.io/work/applied-llm-evaluation/)** — Established an offline evaluation methodology using ground-truth harnesses, Precision/Recall@K, and bootstrap confidence intervals; guided the design of an MCP-based recommendation tool layer.
